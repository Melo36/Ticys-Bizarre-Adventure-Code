# Ticys Bizarre Adeventure

The first game I ever made. A platformer with three levels where each level has a different mechanic. The player character has the ability to jump and grab objects. 

---

## 🚀 Project Overview

* **Level 1:** Basic platformer level with obstacles and moving objects
* **Level 2:** Puzzle where the player has to jump around while avoiding landing on the same platform twice
* **Level 3:** Boss level. Grab bombs and throw them at the boss to beat him

---

## 🛠️ System Architecture & Tech Stack

The project is built using a modern spatial computing workflow optimized for performance and low-latency rendering in medical environments:

* **Game Engine:** Unity 3D
* **Target Devices:** PC with support for Controller
* **Programming Language:** C#
